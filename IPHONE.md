# iPhone’da kullanma

## Safari “redirections” hatası
Eski service worker bu hatayı veriyordu. Güncel sürüm SW’yi kapatır.
**Eski Ana Ekran ikonunu sil**, yeni linki Safari’de bir kez aç, sonra tekrar Ana Ekrana Ekle.

## Açılacak link
Güncel adres PR / agent mesajındaki Cloudflare linkidir (`*.trycloudflare.com`).
jsDelivr kullanma (kod gösterir).

## Ana ekrana ekle
1. Safari ile aç  
2. Paylaş → Ana Ekrana Ekle  
3. Kapatıp açınca çalışır (internet açık olmalı; vakit API’si online)

## Widget
Scriptable → `docs/widget/scriptable-namaz.js`
