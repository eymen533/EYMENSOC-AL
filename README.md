# VAKİT — Namaz Vakitleri

Görsel odaklı günlük namaz vakitleri. 24 renk teması, iPhone ana ekran kısayolu (PWA) ve Scriptable widget.

- Büyük saat + sonraki vakte geri sayım
- İmsak, Güneş, Öğle, İkindi, Akşam, Yatsı
- Türkiye şehirleri (Diyanet yöntemi)
- Tema seçici (şehirin yanında)

## Çalıştırma

```bash
npm run build
npm run preview
```

## iPhone

Kurulum adımları: [IPHONE.md](./IPHONE.md)

- **Ana ekran uygulaması:** Safari → Paylaş → Ana Ekrana Ekle
- **Widget:** App Store’dan Scriptable → `widget/scriptable-namaz.js` yapıştır → Scriptable widget ekle
