# Minik Kalem

İlkokula yeni başlayan çocuklar için harf ve rakam yazma uygulaması.

## Özellikler

- Türk alfabesi harfleri (Ç, Ğ, İ, Ö, Ş, Ü dahil)
- Rakamlar (0–9)
- Dokunmatik / fare ile çizim
- Kesik çizgili izleme şablonu
- Renkli kalemler
- Yıldız ödülü ve tebrik animasyonu
- İlerleme tarayıcıda saklanır

## Çalıştırma

```bash
npm install
npm run dev
```

Üretim derlemesi:

```bash
npm run build
npm run preview
```
