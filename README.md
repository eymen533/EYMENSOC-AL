# Saatli Maarif Takvimi

Klasik **Saatli Maarif Takvimi** tarzında günlük yapraklı takvim uygulaması.

Her yaprakta:

- Gün, ay, yıl ve gün adı
- Hicrî tarih
- İsim günü
- Bugün tarihte
- Günün sözü (atasözü)
- Günün yemeği (malzeme + yapılış)
- Faydalı bilgi / sağlık / pratik bilgi
- Özlü söz

**Sonraki yaprak** ile bir sonraki güne geçilir; yaprak koparma animasyonu vardır. Önceki gün ve Bugün düğmeleri de mevcuttur.

## Çalıştırma

```bash
npm install
npm run dev
```

Üretim derlemesi:

```bash
npm run build
npm run preview
```
