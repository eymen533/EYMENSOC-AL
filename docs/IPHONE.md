## ÖNEMLİ: Siteye son sürümü yükle (tercihler için şart)

Netlify şu an eski Drop dosyasını gösteriyor; renk/şehir bu yüzden kayıt olmuyor.

1. Bilgisayarda Netlify → `adorable-sprite-995f0b` → **Deploys**
2. **Deploy manually** / sürükle-bırak alanına `vakit-deploy.zip` dosyasını bırak  
   (repoda: `vakit-deploy.zip` — veya `docs/` klasörünün zip’i)
3. Publish olunca Safari’de siteyi aç, renk+şehir seç
4. Uygulamayı kapatıp Ana Ekran ikonundan tekrar aç — seçimin kalmalı
