# iPhone — tek uygulama (WebView yok)

Safari / uzak Dash **kullanılmaz**.  
**Pair (Bluetooth) + Cluster** aynı Pulse uygulamasında çalışır.

## Kur

1. App Store → **Swift Playgrounds**
2. Zip: `/downloads/PulsePhoneKey-playground-build16.zip`
3. Dosyalar’da aç → `PulsePhoneKey.swiftpm` → **basılı tut → Paylaş → Playgrounds’ta Aç**
4. Signing (Apple ID) → **Run ▶**
5. Ana ekranda sürüm: **`build-16-native`**

## Kullan

1. **Pair Vehicle** → VIN → `🔑 Tesla …`
2. Key Card → **konsol** → Confirm
3. **Cluster’i ac** — hız, batarya, lastik, seyahat **aynı uygulamada** (internet / WebView gerekmez)

Zip açılmazsa: `/downloads/PulsePhoneKey-swift-files.zip` + [`MANUAL.md`](MANUAL.md)

## Not

Canlı araç telemetrisi şu an cihaz içi demo akışıdır (Pair gerçek BLE’dir). Web sunucusuna veri için bağlanılmaz.
