# iPad Swift Playgrounds — gerçek BLE Pair

## Kur

1. Zip’i indir → `PulsePhoneKey.swiftpm` aç  
2. App Settings → Signing (Apple ID)  
3. Capabilities → **Bluetooth Always** (Package.swift’te gömülü)  
4. Run ▶  

Çökerse: [`CRASH_FIX.md`](CRASH_FIX.md) · [`MANUAL.md`](MANUAL.md)

## Pair

1. Arabayı uyandır, Tesla app kapat  
2. **Bluetooth ile eslestir**  
3. Log: `TX tamam` / `Istek gitti`  
4. Key Card → **konsol** → Pair
