# Salon Tasarımı — Açık Alan & Cam Trabzonlu Merdiven

## Ne değişti?

1. **Ortadaki kapı + ayna duvarı tamamen kaldırıldı** → salon daha geniş ve açık.
2. **Merdivenle birleşen ara duvar kaldırıldı** → salon ve merdiven tek hacim.
3. **Merdiven trabzonları cam** → temperli cam paneller + ince siyah küpeşte.
4. **Modern dil** → açık meşe, sıcak beyaz, nötr mobilya, bol doğal ışık.
